# Mess Feedback System

## Description
Mess Feedback System is a Python command-line application that allows students to submit and manage feedback and complaints about mess food.

## Features
- Give Feedback
- View Feedback
- Rating Summary
- Rating Distribution
- Submit Complaint
- View Complaints
- Permanent data storage
- Rating validation

## Technologies Used
- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- File Handling
- Exception Handling

## Requirements
Python 3.x

## How to Run

Open the project folder in VS Code and run:

```bash
python main.py
